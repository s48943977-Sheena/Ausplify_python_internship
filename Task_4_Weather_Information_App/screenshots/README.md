---

## 🚀 How to Capture Screenshots on Windows

1. Run the Desktop GUI:
   ```powershell
   python weather_gui.py
   ```
2. Search for a city or click any quick city pill.
3. Press `Win + Shift + S` or `PrtScn` on Windows to capture the screen.
4. Save the images into this `screenshots/` directory using the filenames listed above.
